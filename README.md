# jettt.me 测试报告与用例

面向社区超市销售管理系统 [jettt.me](https://jettt.me/) 的公开脱敏测试文档。

主要测试日期为 **2026-10-23**；2026-10-24补充一项未完成的会话过期观察并整理成文。覆盖五个授权测试账号，采用浏览器手工/探索式黑盒检查。

## 数据摘要

- 主要问题：**18项，P1 8项 / P2 10项**。
- 用例：**81项**，其中 **29通过、25失败、6观察、2部分执行、18未执行、1阻塞**。
- 25个失败断言去重关联18项主要问题，不应当作25个独立缺陷。
- 用例根据现场记录回溯整理并补齐后续设计，**81项并非全部已执行**。
- 所有缺陷、用例和证据编号相互关联；JSON与Markdown来自同一份结构化数据。

## 关键结论

优先处理称重首次加购确认、过期识别与加购警示、今日排行日期口径、补货单位与数量，以及商品详情和角色权限配置。

采购测试账号实际同时具有店长角色，与提供的岗位清单不一致；本人单据有审核入口。**未提交本人审批，不能宣称已验证自审或接口越权漏洞**。过期商品仅检查到加购，未验证最终售出。

## 使用方式

1. 先读测试报告中的范围与限制。
2. 按测试方法准备经授权的角色与演示夹具，不使用本仓库猜测登录信息。
3. 按用例步骤复现，填写新构建号、日期、实际结果和证据。
4. 修复后更新缺陷状态及追溯矩阵；未执行、部分执行和阻塞不能直接改为通过。
5. 涉及支付、库存、审批或资金写入的后续用例，只在隔离、可恢复且另获授权的环境执行。
